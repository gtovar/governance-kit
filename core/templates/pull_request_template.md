# Pull Request Template

> Copy to `.github/PULL_REQUEST_TEMPLATE.md`

## What changes?

- [ ] Feature
- [ ] Fix
- [ ] Refactor
- [ ] Docs

## DoR Checklist (Definition of Ready)

- [ ] Objective and scope are clear (what is included and excluded).
- [ ] Acceptance criteria written and understood.
- [ ] Risks/dependencies identified.

## DoD Checklist (Definition of Done)

- [ ] Lint + tests OK (CI green).
- [ ] Docs/ADR updated if applicable.
- [ ] `PROJECT_STATE.md` and `Sprint_Log.md` updated.

---

> If the reviewer writes **"revisa lógica"**, activate analytic mode:
> identify risks, assumptions, and alternatives before answering.
